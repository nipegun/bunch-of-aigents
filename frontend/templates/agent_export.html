Export

Downloads this agent as a .zip that the + button can import, here or on another installation. Its configuration, its system prompt and its schedules always go in; the rest only if you tick it.

Which files

    Never included, whatever you tick: API keys, the agent's own token, channel credentials, its chat, its run journal, its browser sessions and the hidden files of its home. From its crontab only the schedules that run the agent travel, not other commands.
