Backup model

Used only when the main provider fails: no key, no answer, a model that is not there. Leave the provider on "none" to have a run stop instead.

Where your own server listens.

The backup is the same provider and the same model as the main one, so it cannot answer anything the main one could not. Change one of the two, or set the provider to "none".

Spending ceilings

An agent on a schedule with no ceiling is an open invoice. Every run stops at whichever of these it reaches first.

Tools

A tool this agent is not given is a tool it cannot call. The check runs on the server, not in the prompt.

Skills

Written procedures this agent may read. Only the name and the one-line description of each go into its prompt; it reads the rest with skill.read when it needs it.

A skill also needs the skill.read tool, under Tools.

Skills live in /opt/boa/skills/, one directory each with a SKILL.md inside. Add one there over SSH and it appears in this list.

Channels

Which channels this agent may write to. It never sees their credentials.

A channel also needs the channel.write tool, under Tools.

System prompt

Stored as system-prompt.md in the agent's home directory.

Memory

What the agent wrote down for itself, in memory.md inside its home. It is loaded at the start of every run, so keep it short: all of it is paid for on every model call. You can correct it here.

Cron

This agent's own crontab, owned and run by its own user. One line per job.

Last runs
