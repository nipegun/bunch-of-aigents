Mailbox (IMAP)

The mailbox the mail.* tools read. Agents never see these credentials: they ask the agent API, which runs as boa and holds them. Leave it empty and every mail tool refuses.

Comma separated. An entry starting with @ allows a whole domain. Checked by the server on every forward, not by the agent: a mailbox is read by an agent whose instructions arrive inside the messages it reads, so this cannot be a line in a prompt. Empty means forwarding is refused outright.

Provider API keys

Shared by every agent. An agent can override its own with a keys/<provider>.key file in its home directory, which is how one agent gets billed to a different account.

A key is only handed to an agent configured for that provider, and only when it runs. An agent that legitimately uses a paid provider does hold its key while running: it needs it to make the call.

Channels

Credentials are written to /opt/boa/config/channels/ as root:boa 0640. No agent can read them; agents send through the agent API instead.
