Audio transcription

Voice notes and audio sent to an agent in Telegram are converted to text before the agent answers.

Audio is transcribed on this server. Larger models need more memory and processing time.

Audio is sent to the selected provider. Only compatible providers with a saved API key are listed.

Save an API key for a transcription provider in API keys first.

Choose a suggestion or enter another transcription model offered by this provider.

Use auto to detect the language, or a code such as es or en. Some providers always detect it automatically.

When disabled, only the transcript is kept. Clearing the chat also deletes its saved audio.
